# 更新日志

## 2026-08-31

### 编译下载修复

- 修复用户配置文件末尾意外拼接重复 JSON 后，客户端生成任务提示 `Extra data` 并失败的问题。
- 生成客户端时会自动恢复最后一份完整配置，并在用户配置目录保存损坏原文件备份。
- 配置保存改用写锁和唯一临时文件，降低并发保存造成配置损坏的风险。

### 下载可靠性

- 下载按钮支持主下载地址、备用下载地址和备用网页地址。
- 主地址在解析失败、HTTP 错误、网络连接失败、实际传输失败或分片失败时，自动切换到备用下载地址。
- 备用下载地址仍无法使用时，自动打开配置的备用网页，并在客户端状态栏提示处理结果。
- 暂停、恢复和失败重试会保留备用地址配置，避免任务恢复后丢失回退能力。
- 内置功能下载代理和旧版 HTA 客户端同步支持备用地址回退。

### 后台配置

- 单文件下载配置新增“备用下载地址”和“备用网页地址”。
- 多文件安装包可为每个文件分别配置备用下载地址和备用网页地址。
- 兼容历史 `download_url` 单文件配置，以及 `backup_url`、`backup_download_url`、`fallback_url` 等备用地址字段。
- 多文件安装包继续支持统一目录保存、完成后运行主程序和失败文件单独重试。

### 发布整理

- 正式源码统一保留在 `src/ToolboxAdminApi-oneclick`。

- 发布最新一键包 `packages/toolbox-admin-local-latest.tar.gz`，同步生成 Base64 文件和 SHA256 清单。
- 更新首次部署、保留数据更新命令和管理脚本，使其统一指向最新正式包。
