# 更新日志

## 2026-09-06

### 六版本客户端模板

- 新增调音师工具箱旗舰版，并接入现有后台配置、页面锁、下载容器、队列、并发和断点续传能力。
- 统一更新原版、调音师经典版、调音师简约版、音频工具箱火山版、导航首页版和旗舰版客户端模板。
- 修复五个非旗舰版本的软件大全未启用页面纵向滚动，软件条目超出窗口后无法继续查看的问题。
- 软件大全结果数量改变时会重新计算滚动范围；离开页面后仍按原逻辑清理滚动状态。
- 调音师简约版和旗舰版左侧菜单严格使用后台 `sidebar` 的页面、名称和顺序，不再自动插入未配置的系统工具或固定分类。
- 旗舰版只在 `vst76_home` 或 `system_overview` 页面渲染默认系统概览；后台名称为“首页”的自定义页面继续按后台分组和按钮原样显示。
- 品牌头像保持按后台图片 URL 直接拉取，并在网络请求临时失败后释放失败状态、允许后续同步重新拉取。
- 恢复按钮独立下载目录、按钮退出删除、暂停任务下载策略持久化、可写目录回退和异步退出清理。
- 恢复按钮密码及确认保护、音频版图标固定画布、长文字换行、响应式窗口和焦点状态处理。

### 软件目录与旗舰界面

- 软件大全新增在线目录、搜索、真实图标、动态 GIF 图标和安全下载地址解析，并保留离线目录与 Winget 回退；GIF 图片流在卡片销毁时会同步停止动画并释放。
- 火山版软件大全使用与该版本一致的白底、灰框和红色强调样式，在线时优先显示联想应用商店结果及其图片、评分、下载量和说明。
- 旗舰版补齐首页系统状态、内存清理间隔、系统操作、软件图标、下载进度、下载设置和明暗主题。
- 旗舰版配置了系统概览时，将系统概览固定放在左侧菜单第一项并作为默认打开页面。
- 旗舰版“按钮图文排列”按后台选择的页面统一生效：未选页面全部使用普通按钮，已选页面全部使用软件大全风格卡片，未单独配置图标的按钮也保持同页卡片布局。
- 系统概览根据可用窗口高度自动压缩状态区、工具区和资源入口，完整显示页面内容并禁用纵向滚动条。
- 修复后台软件按钮图片首次进入页面时偶尔只加载一部分的问题；异步请求会登记并更新全部等待控件，页面首次布局重建后会自动补图。
- 普通按钮图片遇到临时网络失败时自动短退避重试，并在请求结束后释放进行中状态，不再要求切换页面重新触发。
- 调整旗舰版侧栏、设置按钮与区块边框，移除不需要的横向滚动条。

### 配置连接

- 单次网络波动不再立即显示断连；连续失败后按指数退避重试，同时保留当前可用配置。

## 2026-08-31

### 编译下载修复

- 修复用户配置文件末尾意外拼接重复 JSON 后，客户端生成任务提示 `Extra data` 并失败的问题。
- 生成客户端时会自动恢复用户配置或客户端完整性记录中的最后一份完整数据，并保存损坏原文件备份。
- 配置保存改用写锁和唯一临时文件，降低并发保存造成配置损坏的风险。

### 下载可靠性

- 下载按钮支持主下载地址、备用下载地址和备用网页地址。
- 主地址在解析失败、HTTP 错误、网络连接失败、实际传输失败或分片失败时，自动切换到备用下载地址。
- 备用下载地址仍无法使用时，自动打开配置的备用网页，并在客户端状态栏提示处理结果。
- 暂停、恢复和失败重试会保留备用地址配置，避免任务恢复后丢失回退能力。
- 内置功能下载代理和旧版 HTA 客户端同步支持备用地址回退。

### 后台配置

- 单文件下载配置新增“备用下载地址”和“备用网页地址”。
- 多文件安装包可为每个文件分别配置备用下载地址和备用网页地址。
- 兼容历史 `download_url` 单文件配置，以及 `backup_url`、`backup_download_url`、`fallback_url` 等备用地址字段。
- 多文件安装包继续支持统一目录保存、完成后运行主程序和失败文件单独重试。

### 发布整理

- 正式源码统一保留在 `src/ToolboxAdminApi-oneclick`。

- 发布最新一键包 `packages/toolbox-admin-local-latest.tar.gz`，同步生成 Base64 文件和 SHA256 清单。
- 更新首次部署、保留数据更新命令和管理脚本，使其统一指向最新正式包。
