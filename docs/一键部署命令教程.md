# 梳理工具箱一键部署 / 更新命令

这条命令同时适用于第一次部署和后续更新。

## 客户一键命令

复制整段到宝塔终端执行：

```bash
cd /www/wwwroot && rm -rf toolbox-admin-oneclick toolbox-admin-oneclick.tar.gz toolbox-admin-oneclick.tar.gz.b64 && mkdir -p toolbox-admin-oneclick && curl -L --retry 5 --retry-delay 3 -o toolbox-admin-oneclick.tar.gz.b64 "https://raw.githubusercontent.com/SHAONIAN697/toolbox-admin-oneclick/main/packages/toolbox-admin-local-latest.tar.gz.b64" && if command -v base64 >/dev/null 2>&1; then base64 -d toolbox-admin-oneclick.tar.gz.b64 > toolbox-admin-oneclick.tar.gz; else python3 -c "import base64,pathlib; pathlib.Path('toolbox-admin-oneclick.tar.gz').write_bytes(base64.b64decode(pathlib.Path('toolbox-admin-oneclick.tar.gz.b64').read_text()))"; fi && ls -lh toolbox-admin-oneclick.tar.gz && tar -xzf toolbox-admin-oneclick.tar.gz -C toolbox-admin-oneclick --strip-components=1 && cd toolbox-admin-oneclick && bash install-baota.sh
```

## 第一次部署

执行后按提示填写：

- 绑定域名：填写客户自己的域名。
- 安装目录：一般直接回车。
- 服务端口：一般直接回车，默认 `5088`。
- 管理员账号：默认 `admin`，也可以填写手机号等实际登录账号。
- 管理员密码：至少 12 位，可手动填写，也可直接回车自动生成。

首次部署完成后，终端会显示后台地址、实际管理员账号和首次密码。

## 已部署客户更新

已经部署过的客户继续执行同一条命令。脚本会自动进入更新模式，并保留：

- 后台账号和密码
- 用户列表
- 邀请码
- 后台配置
- 每个用户的工具箱配置
- `data/` 数据目录

更新前会自动备份原来的 `data/` 目录，避免数据丢失。

更新完成时，脚本会从现有 `data/users.json` 读取并显示启用中的超级管理员账号，不再固定显示 `admin`。已有密码使用加密摘要保存，无法恢复明文；更新不会修改密码。如需重置密码，重新运行管理命令并选择“修改管理员密码”，脚本会修改实际超级管理员账号；存在多个超级管理员时会先要求选择目标账号。

## 常用命令

查看服务：

```bash
systemctl status toolbox-admin --no-pager -l
```

重启服务：

```bash
systemctl restart toolbox-admin
```

查看日志：

```bash
journalctl -u toolbox-admin -n 100 --no-pager
```
