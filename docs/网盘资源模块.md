# 网盘资源解析模块

## 已实现范围

- 个人解析任务、资源和下载任务均使用 `ownerUserId` + `resourceScope=personal` 隔离。
- 总管理员跳过套餐权益检查；普通成员和代理必须拥有本人 `cloud_resolver` 权益。
- 权益来源支持管理员授权、套餐兑换激活码；代理转售库存不会自动开通代理本人权益。
- 解析支持批量链接、Provider 自动识别、备注/版本/平台/架构/语言/标签字段。
- Mock Provider 仅在 `CLOUD_RESOLVER_MOCK_ENABLED` 为真时启用，生产默认关闭。
- 蓝奏云继续使用项目原有解析器；蓝奏云以外的链接统一接入聚合解析 API，按其支持列表覆盖 123 云盘、天翼、夸克、UC、移动、联通、小飞机等平台。未知域名由解析服务判断是否支持。
- 聚合服务 JSON 解析结果和目录文件列表统一转换为项目文件记录；第三方下载地址及所需请求头只保存在服务端，下载继续通过工具箱代理，支持 Range/分段传输。
- 资源分配限定在当前用户自己的页面和分组。同名按钮唯一时复用原按钮并追加线路；多个同名按钮要求显式选择；重复线路跳过。
- 线路支持启用/禁用、优先级、主线路切换、刷新和删除。删除个人资源会同步清理线路摘要。
- 访问码只保存为服务端密文/摘要，不出现在任务、资源、审计响应中。

## 数据文件与迁移

模块使用 `data/cloud-resolver.json`，首次读取时按默认结构补齐字段，不修改旧的用户、按钮、订单或下载数据。主要集合为：

- `entitlements`：用户本人权益和配额使用量；
- `plans`：套餐、会员价、代理拿货价和 Provider 范围；
- `codes`：激活码摘要、库存归属、销售和兑换状态；
- `tasks`：解析任务及标准化文件列表；
- `resources` / `sources`：个人资源和按钮下载线路；
- `downloadTasks`：现有下载引擎接入前的任务记录。

旧版本部署只需将新代码文件发布到服务端，保留 `data/` 即可。建议发布前备份 `data/cloud-resolver.json`。

## 权限与 API

个人接口位于 `/api/cloud-resolver/*`，管理接口位于 `/api/admin/cloud-resolver/*`，代理库存/销售接口位于 `/api/agent/cloud-resolver/*`。所有接口继续使用现有登录会话和审计系统。

总管理员可以管理开关、Provider、套餐、激活码、用户授权、用户资源和用量；代理只能查看自己的库存/销售并销售已分配给自己的卡密；成员只能自行兑换并管理本人资源。

管理员常用接口：

- `PATCH /api/admin/cloud-resolver/settings`
- `PATCH /api/admin/cloud-resolver/providers/{name}`
- `POST /api/admin/cloud-resolver/users/{id}/grant`
- `DELETE /api/admin/cloud-resolver/users/{id}/grant`
- `POST /api/admin/cloud-resolver/plans`
- `POST /api/admin/cloud-resolver/codes`
- `POST /api/admin/cloud-resolver/codes/assign-to-agent`

## 配置与部署

生产环境保持 Mock Provider 关闭，不提交真实访问码或第三方 Cookie/Token。聚合解析服务密钥由总管理员在“网盘资源-解析模块全局设置”填写，在 `data/cloud-resolver.json` 中加密保存；也可由服务器环境变量 `NFD189_API_KEY` 提供。管理接口只返回密钥是否已配置，不返回明文。当前项目 API 地址使用 `https://pan.vst76.cn`，接口说明见 `https://nfd189.qaiu.cn`。解析 API 按服务方规则计费：`/json/parser` 每次请求消耗额度，链接详情和目录列表不消耗；失效下载线路重新解析时可能再次消耗额度。

当前未实现任意下载 URL 代理、验证码绕过、账号密码保存或网盘限速规避。服务端只接受解析服务返回的 HTTPS 公网下载地址，并拒绝指向本机/内网的跳转。

网页后台登录后进入“网盘资源”。客户端配置接口只携带本项目 API 基础路径，客户端不得内置聚合解析 API Key；已有下载器仍由服务端代理返回的正式线路控制。


Mock 示例使用 `mock://fixture/share-1` 和测试文件列表，不依赖真实网盘链接，也不会消耗第三方服务额度。未配置密钥、密钥错误、服务额度不足或平台不支持会分别返回明确错误。
